## 2026-08-16 — Клод (Sonnet 4.6)

### Амир AI Консультант — визуальный экран

**Создан `amir.html`** — интерактивный AI консультант с двумя панелями:
- Левая панель (58%): SVG-холст со схемами
- Правая панель: чат с Амиром

**Подключён DeepSeek API** (`/api/amir` в `_worker.js`):
- SSE стриминг — текст появляется посимвольно
- Новый системный промпт: AI возвращает `[SCHEMA:тип]` или `[DIAGRAM:{json}]` в начале ответа
- Схема переключается ещё до окончания ответа

**Пресетные схемы** (детальные SVG):
- `welcome` — что умеет Амир (6 лучей)
- `irrigation` — автоматизация полива (насос → контроллер → датчики → зоны)
- `club` — монетизация компьютерного клуба (7 потоков дохода)
- `site` — архитектура веб-сайта (CDN → фронт → бэк → БД)
- `agent` — автономный AI агент (оплата → Claude → Codex → DeepSeek → Deploy)

**Динамические схемы** (генерируются AI для любой темы):
- `flow` — вертикальная цепочка шагов (3-6 узлов с emoji + стрелки)
- `map` — карта аспектов (центр + ветки с emoji, радиальный layout)
- Парсер `parseDiag()` извлекает JSON из потока и рендерит SVG на лету

**Консультант на главной (`index.html`) открывается по умолчанию** на десктопе (задержка 600мс).

### Технические детали
- `_worker.js`: добавлен `handleAmir()` с SSE форвардингом DeepSeek stream
- Route: `GET/POST /api/amir`
- Ключ: `env.DEEPSEEK_API_KEY` (должен быть в Cloudflare Pages > Settings > Environment variables)
- Model: `deepseek-v4-flash`, temperature 0.3, max_tokens 600

### Файлы
- `amir.html` — создан (полный интерактивный экран)
- `_worker.js` — добавлены `AMIR_PROMPT` + `handleAmir()` + route `/api/amir`
- `index.html` — консультант открывается по умолчанию на десктопе

# Alsat Safety

Изолированная первая версия B2B-платформы корпоративного обучения и внутреннего контроля промышленной безопасности.

## Локальный просмотр

```sh
python3 -m http.server 8080
```

Открыть `http://localhost:8080/`. Статический сервер показывает интерфейс, но серверная форма требует среду Cloudflare Pages Functions.

## Проверка

```sh
npm run verify
```

## Переменные среды

- `SITE_ORIGIN` — разрешённый origin сайта;
- `TELEGRAM_BOT_TOKEN` — токен бота только в защищённых переменных хостинга;
- `TELEGRAM_CHAT_ID` — получатель заявок;
- `LEADS_KV` — необязательная KV binding для устойчивого rate limit и резервного статуса доставки.

Форма сообщает об успехе только после ответа Telegram API. При подключённой `LEADS_KV` заявка сначала сохраняется со статусом `pending`, затем получает `delivered` или `delivery_failed`.

## Публикация

Проект не публиковался. Canonical URL первой версии выбран как `https://safety.alsat.asia/`; перед деплоем владелец должен подтвердить этот путь или заменить его на согласованный домен.
